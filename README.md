# МПС Каталог — демо-концепт

Кликабельный концепт каталога металлопроката с ценами поставщиков. Все цены и поставщики — тестовые данные.

Страницы: главная, весь каталог, категория «Шпунт Ларсена», типоразмер Л5-УМ, поиск, поставщики, карточка поставщика, услуги.

## Запуск локально

Нужен Node.js 18+. Зависимостей нет.

```bash
npm start
```

Сайт откроется на http://localhost:4173.

## Деплой на Railway

1. Railway → **New Project** → **Deploy from GitHub repo** → выбрать этот репозиторий.
2. Railway сам увидит `package.json` и запустит `npm start`. Порт берётся из переменной `PORT`, которую Railway задаёт сам.
3. **Settings → Networking → Generate Domain** — получить публичный адрес.
4. По желанию закрыть сайт паролем: **Variables** → добавить `DEMO_PASSWORD` (и при необходимости `DEMO_USER`, по умолчанию `demo`). Браузер спросит логин и пароль.

Сайт закрыт от поисковиков: заголовок `X-Robots-Tag: noindex` и `robots.txt` с `Disallow: /`.

## Структура

| Путь | Что там |
| --- | --- |
| `design/*.html` | страницы |
| `design/styles.css` | дизайн-токены и компоненты |
| `design/site.js` | шапка, меню, подвал, поиск — общие для всех страниц |
| `design/data.js` | тестовые данные: каталог, профили шпунта, поставщики, услуги |
| `design/assets/` | логотип |
| `server.js` | сервер для Railway и локального запуска |
| `tools/check.js` | проверка файлов перед коммитом (`npm run check`) |
| `tools/build-publish.js` | сборка в один файл на страницу для публикации на claude.ai |
